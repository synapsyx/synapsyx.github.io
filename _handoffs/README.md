# _handoffs

Handoffs, work orders and browser-model exchanges for this repository follow the owner's estate handoff convention (`~/Developer/syxOS/_handoffs/README.md`, on the owner's machine). Author them with the estate handoff-writer skill.

This repository is public, so handoff contents stay private. `.gitignore` ignores everything in `_handoffs/` except this README. Never force-add, commit or push handoff files. They have no Git history here, so consumed orders stay flat instead of being retired.
